# 🚀 Pranathi Portfolio [Link :https://portfolio-cyan-psi-54.vercel.app/]

A modern and responsive developer portfolio built using **React.js**, **Vite**, and **Tailwind CSS** showcasing projects, skills, certifications, coding profiles, and achievements.

---

## 🌟 Features

* 🎨 Modern UI/UX Design
* 📱 Fully Responsive Design
* 🚀 Smooth Animations using Framer Motion
* 💼 Detailed Project Pages
* 🏆 Certifications Section
* 📊 GitHub Stats Integration
* 👩‍💻 Coding Profiles Section
* 📄 Resume View & Download
* 📬 Contact Links (GitHub, LinkedIn, Email)

---

## 🛠️ Tech Stack

### Frontend

* React.js
* Vite
* Tailwind CSS
* Framer Motion
* React Router DOM

### Libraries & Tools

* React Icons
* GitHub Readme Stats API

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/PranathiNagisetti/portfolio.git
```

### 2️⃣ Navigate to Project

```bash
cd portfolio
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start Development Server

```bash
npm run dev
```
